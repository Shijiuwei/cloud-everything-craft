## Fixes and causes

| Problem                                                             | Cause and correction                                                                                                                                                                                                                                                                                                 | Commit                                                           |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Interrupted drawings could survive into a later gesture.            | The shared overlay omitted lost-pointer-capture cancellation. Capture loss and pointer cancellation now clear only the owning pointer's gesture and preview, across drawing, shape, area highlight, crop, and link tools.                                                                                            | `3996d43`                                                        |
| Shape constraints and previews lagged behind a stationary pointer.  | Preview updates depended on pointer movement. Shift changes and workspace scrolling now recompute from the last pointer position; repeated updates do not add ink samples.                                                                                                                                           | `17a5f0d`                                                        |
| Tab could return to the numeric field just edited.                  | Commit-time control rebuilding interfered with native blur/focus order. Shared image/shape commits start immediately, mark actions unavailable during native focus movement, and restore the destination only after focus and commit settle.                                                                         | `fe725d4` (supersedes the incomplete timing change in `b5c5533`) |
| Clicking a link opened its destination instead of allowing editing. | Link hit targets were anchors or immediate navigation buttons and had no editing operation. A click now opens a prefilled editing dialog; following the link is explicit. Updates retain annotation identity, bounds, and appearance. Cancel and unchanged saves leave history and precise page destinations intact. | `8ab4b9f`                                                        |
| Double-clicking another text box intermittently lost selection.     | Saving the preceding box clears text targets during redraw. The second click could reach the workspace and cancel the pending selection. The stable workspace now owns that pending second press through redraw.                                                                                                     | `e9ed233`                                                        |

No coordinate offsets or animations were added to conceal these issues. Gesture cancellation, preview updates, property commits, and selection ownership are handled in their shared paths. The link destination validator is shared by creation and editing.

## Boundaries

Mobile checks use Chromium device emulation; WebKit automation does not constitute a native Safari session. No Firefox or assistive-technology session was performed. Three intentionally skipped WebKit cases require Chromium's touch protocol or clipboard permission emulation; their Chromium counterparts are exercised. The fourth skip is mouse-driven thumbnail edge scrolling on the mobile project, where touch is intentionally reserved for scrolling. Existing limitations include unsupported PDF structures, subset-font fallback differences, and the temporary stacking of image drag previews above surrounding content. Text deletion remains editing, not secure redaction.
